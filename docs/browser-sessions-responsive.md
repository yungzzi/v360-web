# 登录保持与屏幕适配

登录时可勾选“在此设备记住登录 15 天”，固定十五天到期，不因访问无限续期。不勾选时使用浏览器会话 Cookie，服务端最长十二小时；浏览器恢复上次会话时可能保留 Cookie，所以仍以服务端到期时间为准。页面刷新自动检查登录，不自动连接摄像头。退出撤销当前浏览器会话，同浏览器其他页面会随状态检查退出，正在观看的连接每秒检查撤销/到期并释放。

未设置独立密码时使用网页 API 令牌登录；设置后使用独立密码。原始密码或 API 令牌不进入 localStorage、sessionStorage 或 URL，独立密码及会话在 SQLite 中只存校验值或摘要；API 令牌仍保存在私有 `web.json` 中供维护使用。浏览器使用独立随机登录凭据，HttpOnly、SameSite=Strict；云端 Secure；路径限于部署前缀下的 /api/。SQLite 只保存登录凭据摘要、到期时间及当前网页令牌的摘要指纹。修改网页令牌会使旧登录失效，离线恢复数据库也清空登录表，防止已退出的登录重新有效。后端重启保留尚未到期的登录。最多允许 32 个有效浏览器会话，不会为了新设备静默踢掉其他设备。

保留已有 Bearer API 调用方式；浏览器 REST、文件和 WebSocket 使用 Cookie，Cookie 访问检查来源。旧媒体 Cookie 只用于原有 Bearer 客户端，新的浏览器会话不另发独立媒体凭据。

界面增加窄屏垂直排列、日期/归档设置整行布局、录像按钮换行、最小 44px 点按区域、48px 云台按钮、输入字号 16px、键盘焦点、全屏能力回退提示。仍使用浅色风格。声音及三画面已分别实现，详见 [声音](live-audio.md) 和 [镜头](multi-lens.md)。

历史验收：当时 131 项软件检查通过；当前期限已改为十五天并补充固定到期检查。覆盖 Cookie 属性、非记住登录到期、重启保持、退出撤销、令牌更换失效、跨来源拒绝、路径前缀、连接退出、设备数量限制、数据库恢复清空登录。Edge 本地隔离数据完成登录、刷新保持、后端实际重启后保持、退出刷新要求重新登录。在 320/390/844/1440px 宽度分别检查实时页和录像页，未出现横向溢出。这些是电脑浏览器尺寸模拟，不是实际 Android/iOS 播放或全屏验收；没有为 UI 验收连接摄像头。
