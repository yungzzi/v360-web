# 自动电量和云台点按

设备标题旁显示电池图标和百分比，填充比例跟随电量；低于或等于 20% 用低电量颜色。未知显示横线，过期值降低强调并保留读取时间。充电标记仅代表设备返回的外接充电字段，不判断太阳能板工作情况。

## 自动更新

每个共享直播会话只建立一个控制工作线程，复用原摄像头连接及命令通道。观看开始后立即读取一次电量，随后每 300 秒再次读取，直接更新设备私有缓存，不受旧的手动诊断命令 15 分钟缓存限制。页面只读本地缓存，已移除手动读取按钮。最后一个观看者退出时结束控制线程，没人观看时不建立电量查询连接。

命令响应按完整头和长度累积处理，保留部分读取，不把 SDK 每次读取当成一个完整响应。异常保留旧电量。控制错误记录在直播状态中；状态读取不会为了取电量唤醒摄像头。

真实摄像头进行了 315 秒观看测试：开始后约 9.51 秒首次取得电量，约 309.77 秒再次取得电量，两次相隔约 300.26 秒。总计 4,636 帧、308 个输出分片，停止后 state=stopped/viewers=0/error=null，控制线程退出。原始私有时间及电量值保存在 `.private/automatic-battery-validation.json`，不入 Git。设备电量估算在不同读取间有波动，尚未与原 App 同时校对，不把数值差直接等同真实耗电。

## 云台

观看后启用上下左右与停止按钮。每次点按给服务端一个约 0.4 秒的移动有效期，控制线程检查到期后发停止命令；这是服务端请求期限，不是物理转动持续时间的精确承诺。停止观看、切走窗口、关闭页面时也请求停止；最后观看者离开时释放整个会话。

仅已认证并持有活动观看者标识的请求可控制。多窗口同时操作时，当前移动者短期占用控制权，其他移动请求返回忙；停止操作优先允许。独立于浏览器计时，即使前端未能发出停止，后端仍会在有效期过后请求停止。网络、SDK 或设备故障下不能保证摄像头一定收到停止命令。

REA 已核对原 App：命令 4097，八字节载荷为方向、8、0、0、0、镜头通道、速度、0；普通摄像头调用通道 0、速度 3。上/下/左/右/停分别为 1/2/3/6/0。没有开放巡航、预置位或任意原始指令。本机真实网页已点按左右、上下和停止，左右画面可观察到位移；试验后做了反向点按使方向接近原位置，未测量角度或保证精确回位。上下的机械行程和端点尚未专门验收。

软件检查覆盖五分钟调度、部分响应读取、同会话查询、移动有效期停止、观看者离开、控制权争用、未认证拒绝和无活动观看者拒绝。真实网页测试停止时累计 2,595 帧，viewers=0，应用没有剩余子进程。阿里云资源和长期稳定性仍待验收。
