# 摄像头电量

浅色页面已加入电量、设备报告的外接充电状态、读取时间和手动读取按钮。页面轮询只访问本地缓存，不连接摄像头；15 分钟内重复读取复用缓存。过期仍展示旧值和待更新标志。读取失败保留旧结果，非法百分比及未知充电标记显示未知。

当前读取与直播/SD 任务共用摄像头锁，观看时点击读取会提示先停止观看。复用活动直播连接的自动低频读取尚未实现。外接充电字段不能代表太阳能板的发电状态。

CLI：在工程目录运行 `.venv/bin/v360 battery`。API：认证后 POST `/api/jobs/battery`，查询现有任务接口；GET `/api/status` 返回缓存中的 battery。缓存按设备区分，存放在私有数据目录，不入 Git。

REA 核对原包：请求 912，四字节零载荷，响应 913。App 的 `Connect.readCmd` 将命令编号置于解析对象前，电量构造器读取偏移 4/8/12；本工程 CameraClient 已移除该编号，实际载荷的对应偏移为 0/4/8。真实响应为 12 字节。首次误将构造器偏移直接套用至载荷而严格拒绝短包，随后核对调用链并修正；没有用补零方式吞掉格式问题。

真实查询曾返回 (47,42300,0)，稍后另一次返回 (39,35100,0)。电量分别按设备报告显示 47% 和 39%，尚未与原 App 同时对照或验证电量估算稳定性；不将这些短时变化直接解释为实际消耗。电压单位未知，保留原值，不向用户显示换算电压。外接充电字段按 0/1 解析，其他值为未知；此次只实际观察到 0。

Edge 已显示 39%、读取时间、未报告外接充电；重复读取通过缓存任务完成。没有据此宣称太阳能充电状态、低电提醒或长期稳定性已验收。当前软件检查总数为 76 项。
