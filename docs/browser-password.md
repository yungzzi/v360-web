# 中文网页访问密码

网页登录改为JSON提交password，支持汉字、字母、数字及空格，避免浏览器
Authorization请求头无法承载汉字。未设置独立密码时，原访问令牌仍可从
网页登录；设置后，网页表单使用新密码。程序接口Bearer令牌保持不变。

回放页→管理与诊断→修改访问密码：输入当前密码，新密码及确认。新密码
8至128个Unicode字符，不静默去除首尾空格。服务器保存16字节随机盐与
PBKDF2-HMAC-SHA256（210000轮）校验值，不保存密码明文。凭据在私有SQLite
中，随既有数据库备份持久化。修改需要当前密码校验及已有登录，限制
密码尝试频率；更新后原浏览器会话及旧媒体会话失效，新密码重新登录。
API维护令牌仍可鉴权及作为已有管理权限的恢复证明。

## Windows中文输入兼容

部分浏览器/输入法组合在type=password时限制IME。四个密码字段新增明确
的显示并输入中文按钮，真实切换为type=text，保留内容及光标；默认隐藏，
关闭管理窗口、退出、提交登录和pagehide时恢复隐藏。不是仅靠浏览器自带
的视觉显示按钮。输入中文时文字可见，页面有相应提示。新增Node检查覆盖
真实类型切换、光标/内容保留与隐藏复位，中文JSON提交检查仍通过。

API令牌保存在服务器/srv/v360-web/config/web.json，既有备份流程也复制
web.json到私有升级快照。建议另存密码管理器，不提交Git或公开发送。
个人笔记丢失可从服务器配置找回；有服务器管理权限时也可更换令牌或
重置网页密码，令牌不是不可恢复的摄像头硬件密钥。已设独立密码后，
日常网页登录使用该密码，无需再次输入API令牌。
