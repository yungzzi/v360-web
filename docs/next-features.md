# 已知限制与后续方向

当前已实现声音、电量自动更新、云台、三画面切换、中文访问密码、十五天登录、家庭界面、自动保存和 Docker 云部署；它们不再列为待开发任务。日常使用以 [README](../README.md) 为准。

## 保留的限制

- 当前只适配已分析的 V360 Pro 7.2.0 和实测设备路径，不承诺通用摄像头兼容。
- 设备拒绝下载、连接超时和异常目录尚无保证成功的修复机制；不能承诺所有历史录像可取或每批零缺口。停止项保留并可手动重试。
- 长时间观看可能占用设备，延迟后台保存。三个观看窗口只能共享同一镜头，不支持三镜头同时播放。
- 两个附加画面只直播，不归档；不做全天连续录像或双向对讲。
- 电量为设备返回值，尚未做充放电校准，不能用它推断精确续航。
- 桌面浏览器检查和尺寸模拟不能代替所有实际手机、系统键盘、音频及全屏体验验证。
- 无手机后端仍依赖私有 Android 运行库和厂商连接服务，并非独立于厂商的设备固件。

## 可考虑的收尾工作

1. 更多实体手机上的登录、触摸时间轴、声音和横屏回归。
2. 稳定域名及设备兼容性准备后，再考虑指纹/解锁登录的通行密钥；当前没有实现。
3. 对实际失败率、最早可回放日期和存储增长做长期观察，以真实数据调整策略，不提高成功率承诺。

这些是候选方向，不表示已安排实施。旧版三十分钟全部就绪目标已经由 [半小时批次发布](scheduled-publication.md) 替代，历史失败不因目标调整而消失。
